# Die Runde

Feldwerkzeug für die Hotelakquise in Dresden. Eine Seite, keine Anmeldung,
läuft auf dem Telefon wie eine App.

**Öffnen:** https://kevin-spec165.github.io/runde/

## Was sie kann

- 105 unabhängige Hotels und Pensionen in Dresden, Ketten und Häuser ab vier
  Sternen sind bewusst nicht dabei
- Laufroute ab dem eigenen Standort oder ab einem gewählten Haus, optimiert
  auf möglichst wenige Kilometer. Uferwechsel über die Elbe werden mit
  einem Umweg-Aufschlag gerechnet, weil man dort zu Fuß über eine Brücke muss
- Navigation per Fingertipp direkt nach Google Maps
- Gesprächsstand je Haus: in Bearbeitung, Wiedervorlage mit Datum,
  Zimmer zugesagt, kein Interesse
- Wiedervorlagen kommen am fälligen Tag von selbst nach oben
- Merkliste, Suche, Namensfeld für mehrere Leute

## Auf dem iPhone einrichten

In **Safari** öffnen, unten auf das Teilen-Symbol, dann
**„Zum Home-Bildschirm"**. Danach startet sie im Vollbild mit eigenem Symbol.

## Wo der Arbeitsstand liegt

Ausschließlich auf dem Gerät, im Speicher des Browsers. Nichts wird
hochgeladen, es gibt kein Konto und keinen Server. Der Knopf
„Stand kopieren" legt eine Zusammenfassung in die Zwischenablage.

## Daten
